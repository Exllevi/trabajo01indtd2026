# Trabajo 01 Teoría de la Decisión - Javier Ribelles Sánchez

## Descripción

Este repositorio contiene el primer trabajo individual de la asignatura, y reúne dos problemas de métodos de incertidumbre, junto con sus correspondientes resoluciones, utilizando las funciones de R proporcionadas. El primer problema es un caso inventado llamado "Decisión cinematográfica Óscar 2027", y el segundo problema está basado en una situación real llamado "Decisión de salud pública sobre el control del OxyContin". El trabajo se ha realizado mediante Git y GitHub.

## Contenido del repositorio

- **Carpeta "problemas:** Que contiene un documento Rmd con los enunciados de los dos problemas y sus versiones en HTML y PDF.

- **Carpeta "soluciones":** Que contiene un documento Rmd con las soluciones de los dos problemas y sus versiones en HTML y PDF.

- **Carpeta "recursos":** Con el archivo de funciones auxiliares "teoriadecision_funciones_incertidumbre.R".

## Herramientas utilizadas

R, RStudio, Quarto, Typst, Git y GitHub.
